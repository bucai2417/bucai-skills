# Changelog

## 1.0.0 - 2026-11-10

- 初始版本：PyMuPDF 主引擎 + pdfplumber 交叉校验/表格 + pypdf 元数据/表单。
- 输出 JSON（schema v1）与阅读顺序 Markdown、纯文本。
- 支持双栏/三栏阅读顺序、页眉页脚/页码识别、表格、链接、目录、表单、附件、图片元数据。
- 质量信号与警告：无文本层、扫描件、CID 字形、替换字符、文本/表格交叉校验差异、页码裁剪、大文档、图片大小限制。
- 加密 PDF 显式密码支持与 owner/user 权限识别；不爆破密码。
- 动态生成测试样本的 17 项端到端测试。
