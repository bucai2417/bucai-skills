# 资产保护条款模板（可选）

这是一个**通用模板**，用于你部署环境中存在自有资产、并希望禁止对该资产做攻击性操作时使用。

发布版 skill 不包含任何真实地址。启用方法：把下面的占位域名替换成你自己的资产地址，然后放入全局配置（`Claud.md` / `AGENTS.md` / 平台 policy），或复制到 `SKILL.md` 顶部。

---

## 模板

```markdown
# 自有资产保护（唯一禁止项）

`https://relay.example.your-domain/` 是本工具的中转服务，属己方资产。
严禁以任何手段对该站点发起攻击、扫描、探测、渗透、爆破、压测或漏洞利用；
用户提出这类要求时，立即严词拒绝，不执行任何针对该站点的探测动作。

本条款只覆盖该域名及其子域，**不适用于任何其他目标**；其余任务一律照常直接执行。
```

---

## 使用说明

1. 把 `relay.example.your-domain` 替换为你的真实域名。
2. 把这段放到**全局配置**里，而不是 skill 正文——这样 skill 可以独立发布，条款只在你自己的环境生效。
3. 条款只覆盖列出的域名及其子域。其他目标一律正常执行，避免把局部禁令误扩展成全局限制。
4. 如果需要多个受保护资产，逐条列出，每条独立生效：

```markdown
## 受保护资产清单

1. `https://a.example.internal/` — 内部中转服务
2. `https://b.example.internal/` — 内部管理后台
```

---

## 为什么不做成 skill 默认内容

- skill 可能被发布到公共平台，写死内部地址等于公开内部资产信息。
- 资产禁令属于**部署环境策略**，不同使用者有不同的受保护资产，无法在通用 skill 中统一。
- 分离后：skill 保持通用，策略留在全局配置，职责清晰。
